# 功能列表

> 整理日期：2026-11-02。路線見 [roadmap.md](roadmap.md)，規格見 [spec_v1.md](spec_v1.md)，決定的理由見 [decisions.md](decisions.md)。
> 對照基準：NNGS 1.1.22 的指令（見附錄）。

## 0. 如何閱讀

**階段**

| 標記 | 意思 |
| --- | --- |
| M1 | 里程碑 1：能完整下一盤圍棋 |
| M2 | 里程碑 2：對局功能補齊 |
| M3 | 里程碑 3：社群功能與帳號 |
| 未來 | 已確定要做，但排在 M3 之後，順序未定 |
| 不做 | 目前不打算做（原因寫在備註） |

**目前狀態**

| 標記 | 意思 |
| --- | --- |
| PoC | 已在 `poc/go-lobby` 分支的 Go 大廳 PoC 實作並測試過（尚未是正式程式碼） |
| 規格 | 已寫進 [spec_v1.md](spec_v1.md)，尚未實作 |
| — | 尚未設計 |

**難度**

| 標記 | 意思 |
| --- | --- |
| 低 | 範圍小、做法明確 |
| 中 | 牽涉多個服務或前後端，但做法明確 |
| 高 | 範圍大，或有尚未驗證的技術風險 |

目前**還沒有正式程式碼**；正式實作從 M1 開始。

## 15. 不做的項目與原因

| 項目 | 原因 |
| --- | --- |
| 文字指令介面、指令別名、客戶端設定 | 改用網頁介面（NNGS 的 `alias`、`set`、`toggle`、`client`、`help`、`next`、`translate`、`ping`、`ayt` 等） |
| 聊天頻道、表情指令、提醒聲 | 網頁介面另有做法，或價值低（`channel`、`emote`、`beep`、`bell`、`it`、`git`、`zz`） |
| 天梯 | 等級分與排行榜已涵蓋需求 |
| 日本規則 | 恢復對局在數目法下會影響目數，終局處理要另一套程序 |
| 對局中改貼目 | 貼目在建房時設定 |
| 寄信相關功能 | 改用網頁下載（`mail`、`mhelp`、`mmess`） |

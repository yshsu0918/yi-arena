## 0. 如何閱讀

**階段**

| 標記 | 意思 |
| --- | --- |
| 現在 | 現在要做，規格在 [spec_v2.md](spec_v2.md) |
| 未來（優先） | 未來要做，排在最前面：需要正式帳號的功能（社群、等級分、第三方登入），見 roadmap 3.1 節 |
| 未來 | 未來要做，順序未定，見 roadmap 3.2 節 |
| 不做 | 目前不打算做（原因寫在備註） |

**目前狀態**

| 標記 | 意思 |
| --- | --- |
| PoC | 已在 `poc/go-lobby` 分支的 Go 大廳 PoC 實作並測試過（尚未是正式程式碼） |
| 規格 | 已寫進 [spec_v2.md](spec_v2.md)，尚未實作 |
| — | 尚未設計 |

**難度**

| 標記 | 意思 |
| --- | --- |
| 低 | 範圍小、做法明確 |
| 中 | 牽涉多個服務或前後端，但做法明確 |
| 高 | 範圍大，或有尚未驗證的技術風險 |

目前**還沒有正式程式碼**。

## 15. 不做的項目與原因

| 項目 | 原因 |
| --- | --- |
| 文字指令介面、指令別名、客戶端設定 | 改用網頁介面（NNGS 的 `alias`、`set`、`toggle`、`client`、`help`、`next`、`translate`、`ping`、`ayt` 等） |
| 表情指令、提醒聲 | 網頁介面另有做法，或價值低（`emote`、`beep`、`bell`、`it`、`git`、`zz`）；聊天頻道排在未來（優先） |
| 日本規則 | 恢復對局在數目法下會影響目數，終局處理要另一套程序 |
| 訪客登入 | 簡易註冊已經夠簡單，訪客沒有意義（D-30） |
| 寄信相關功能 | 改用網頁下載（`mail`、`mhelp`、`mmess`） |
